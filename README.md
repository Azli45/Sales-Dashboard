# Sales Dashboard (Power BI)

An interactive Power BI dashboard for analyzing sales performance — built to surface trends, top performers, and key KPIs at a glance.

## 📊 Overview

This project is a `.pbix` Power BI report that visualizes sales data, helping stakeholders track performance across key dimensions (e.g., time, region, product, and sales rep).

## 🛠️ Tools & Tech

- **Power BI Desktop** — data modeling, DAX measures, and visualization

## ✨ Features

- Interactive filters and slicers for dynamic exploration
- KPI cards for at-a-glance metrics
- Trend charts for time-based sales analysis
- Breakdown by category/region/rep (edit to match your actual report)

## 📂 Repository Contents

| File | Description |
|---|---|
| `sales_dashboard.pbix` | Main Power BI report file |
| `README.md` | Project documentation |

## 🚀 How to Use

1. Download `sales_dashboard.pbix`
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
3. Explore the report using the slicers and filters
4. Refresh data if you've connected your own data source
